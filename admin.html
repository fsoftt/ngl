Inicia sesión con tu clave de GitHub para editar el contenido del sitio.

¿Cómo obtengo mi clave?
  1. Inicia sesión en GitHub con una cuenta que tenga acceso al repositorio .
  2. Abre Crear token (fine-grained).
  3. En Repository access elige Only select repositories y selecciona el repositorio.
  4. En Permissions → Repository permissions pon Contents: Read and write.
  5. Genera el token, cópialo y pégalo aquí. Guárdalo en un lugar seguro: no lo compartas.
